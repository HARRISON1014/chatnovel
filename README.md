# ChatNovel

面向长篇小说创作的开源 AI 写作工作台。

当前仓库处于方案阶段。设计目标是让作者能够从故事概念、世界观和人物设定开始，逐步完成大纲、场景、章节和成稿，同时保留完整的版本记录、上下文来源和人工审核权。

目前仅包含设计文档，尚无可运行版本，开源许可证待确定。

核心设计决定：产品层不绑定任何模型供应商。系统通过统一的模型适配器同时支持云端 API、OpenAI 兼容接口和本地模型服务；首个可用版本优先验证写作工作流，再逐步增加本地推理和高级检索能力。
